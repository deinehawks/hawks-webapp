# ASIMOV-HAWKS Web Application

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

### Install Dependencies

To install the required dependencies, run:

```bash
npm install
```

### Run the Development Server

To start the development server, use the following command:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Additional Notes

- If you encounter issues with dependencies during installation, using the `--legacy-peer-deps` flag is a safe workaround.
- If a Turbopack related error surfaces after starting the development server, delete the `.next` directory and start the server again. Otherwise, remove the --turbopack flag in the start command.
- Removing the turbopack flag will significantly slow down the compilation process of the source code.
